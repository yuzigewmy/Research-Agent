# 工程项目预览

用「工程项目」模板建项。在「文本工作区」保存一个 `.html` 或 `.htm` 文件，页面可包含内联脚本、内联样式和数据 URL 图片。到「工程预览」刷新文件列表，选择已保存的版本并启动。预览显示文件路径、版本和 SHA-256。

每个工程项目有一个活动预览。再次启动相同版本会复用原地址。保存同名文件的新版本后，当前预览继续显示原版本。选择新版启动后，旧地址即失效。关闭预览或归档项目也会使原地址失效。服务重启后可恢复活动预览。

预览采用隔离的浏览器框架。页面脚本在独立的浏览器源中运行。内容策略允许内联脚本和样式，限制连接、表单、第三方子框架和远程资源。此版面向单文件静态页面。依赖安装、服务端代码运行、预览日志与远端执行节点属于后续工程能力。 [浏览器沙箱指令](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/sandbox)

管理接口为 `/api/v1/projects/{id}/preview`。`GET` 读取活动预览，`POST` 提交 `versionId` 启动预览。`DELETE /{previewId}` 关闭指定预览，旧编号不能关闭后续开启的实例。框架使用 `GET /{previewId}/document` 读取原始 HTML，响应包含 `X-Source-SHA256`。

Go 回归核对版本固定、模板和项目范围、替换与关闭。Chrome 联测核对工作区保存、预览内交互、同名改版、刷新恢复、停止和归档。
