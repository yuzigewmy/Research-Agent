# 互动问卷

从「互动问卷」模板建项，编辑问卷标题、卷首语和题目。首版支持单选和文本题，可逐题设为必答。草稿可反复保存。点击「发布问卷」后，当前修订成为填写页内容。复制链接即可在能访问同一工作台的浏览器打开填写页。点击「关闭回收」后停止接收新答卷，可继续下载已有数据。

## 数据与回收

- 问卷包含 1 至 20 道题。题目的编号与顺序决定导出列。每道单选题支持 2 至 12 个选项。
- 一次填写产生一条答卷回执。同一提交编号重试且内容一致时复用回执。每份问卷最多收集 1000 份答卷。文本题单项回答最多 320 个 UTF-8 字节，单份答卷的编码数据最多 7 KiB，以便回收数据能直接选入问卷分析。
- 管理页显示回收数量。答卷可下载为 CSV，也可保存至项目资料。打开「问卷分析」并刷新文件列表，选择导出的资料版本即可清洗和统计。
- CSV 包含答卷编号、提交时间、回收来源和各题的答案。项目资料按 CSV 摘要保存不可变版本。导出时会处理电子表格可能识别为公式的单元格。

## 分析工作簿

把不超过 8 MiB 的 XLSX 上传到项目资料。在「问卷分析」中选定文件和工作表，再点击「开始分析」。首个非空行用作表头，后续空行会跳过。复核时可同时查看答卷顺序和 Excel 原行号。清洗、复核和统计重算均沿用报告记录的原文件版本和工作表。

工作台读取原始数值、文本、布尔值和工作簿已保存的公式结果。需要刷新公式结果时，先在电子表格应用中计算并保存。日期和百分比等格式沿用单元格的原始值。表头请整理为一行，每列填写独立列名。 [单元格值说明](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/how-to-retrieve-the-values-of-cells-in-a-spreadsheet)

## 交叉统计

在「问卷分析」开始分析所选数据，按需应用清洗规则和复核答卷。打开报告后，用「行分类」和「列分类」选择两个不同字段，点击「计算交叉统计」。表格仅计入两列均有回答的有效答卷，并显示缺失份数、各格次数及行列合计。每个字段最多 20 类，每个类别名最多 128 个 UTF-8 字节；适合单选或分组字段。

再次复核会按相同字段重算，生成独立报告。报告与 JSON 下载均保留原资料版本及 SHA-256。刷新文件列表发现同名新版时，旧报告仍可查看和下载；选择新版开始分析才会切换数据来源。

## 分类编码

展开分析报告的「分类编码」，选择统计列并填写原值和目标类别。例如，可以把「北岸站」归入「北岸」。应用编码会生成新报告，沿用当前报告的清洗规则、复核决定、工作表和权重设置。

频次和交叉表按编码后的类别汇总。匹配前去除首尾空白，区分大小写，每个回答只查找一次。未匹配的值沿用原类别。清洗判定和数值统计使用原始回答。支持最多 64 条规则，原值和目标类别各限 128 个 UTF-8 字节。创建分析时可通过 `options.categoryMappings` 提供 `column`、`from` 和 `to`，报告下载包含保存的规则。

## 沿用历史分析设置

先分析新版答卷。在新报告中展开「沿用历史分析设置」，选择同项目的历史报告，逐项确认源列与目标列。界面会预选同名字段。确认后按新版资料与工作表生成独立报告，沿用映射后的必答、查重、权重、分类编码和统计设置。请从新版报告的「答卷明细」重新复核。

报告页面和 JSON 下载记录来源报告编号与确认过的字段对应。接口 `POST /api/v1/projects/{id}/surveys/{analysisId}/map-settings` 接受 `requestId`、`targetAnalysisId` 和 `fields`，其中每组字段使用 `from` 和 `to`。

## 量表信度

在分析报告的「量表信度」中选取同一量表的 2 至 20 个数值题项，再点击「计算量表信度」。请先统一计分方向，例如在上传前完成反向题的反向计分。

Cronbach α 使用清洗和复核后有效且所选题项均为数值的答卷。报告分别列出纳入、缺失和非数值的份数。少于两份完整答卷或总分没有变异时，报告只显示样本计数。再次复核会重算并保存新报告，历次结果均可按原资料版本查看和下载。

## 一元线性回归

在报告的「一元线性回归」中选择不同的自变量和因变量，点击「计算回归」。报告使用带截距的普通最小二乘法，按原单位给出截距和斜率，并列出 R²。计算只纳入清洗及复核后有效、两列均为有限数值的答卷。一列缺失时记为缺失，其余非数值配对单独计数。

拟合需要至少两份完整数值配对，且自变量须有变异。因变量为常量时，报告保留系数，R² 未定义。复核后会按原资料和已选变量重算，形成独立报告供查看和下载。分析请求通过 `options.regression.predictorColumn` 和 `options.regression.outcomeColumn` 指定两列。

## 样本量与分析计划

在「问卷分析」中展开「样本量与分析计划」，填写研究目标、目标总体、抽样方式、计划统计方法、缺失值处理策略和样本量参数，实时预览结果后点击「保存计划版本」生成不可变版本。历史版本按版本号倒序保留，可随时回填查看或修改后保存新版本。

样本量采用固定 Cochran 比例抽样口径（`proportion-cochran-v1`）：置信水平仅支持 90%（`z = 1.6448536269514722`）、95%（`z = 1.959963984540054`）或 99%（`z = 2.5758293035489004`）；预期比例 `p ∈ (0, 1)`，默认 `0.5`；允许误差 `e ∈ (0, 0.5)`，默认 `0.05`；可选有限总体 `N ∈ [1, 1,000,000,000]`（留空或 `0` 表示无限总体）；预期有效回收率 `r ∈ (0, 1]`，默认 `1`。基础样本量 `n₀ = ⌈z²·p·(1−p)/e²⌉`；指定有限总体时按未取整基础样本量校正 `n_fpc = ⌈n₀,raw / (1 + (n₀,raw − 1)/N)⌉`；计划发放量 `n_planned = ⌈n_fpc / r⌉`。固定核对样例：95%、`p = 0.5`、`e = 0.05` 时无限总体为 `385`，`N = 1000` 校正为 `278`，`r = 0.8` 时计划发放 `348`（99% 同条件下为 `664`、`400`、`500`）。

发起「开始分析」时可选关联同项目的任一计划版本。报告详情与下载的 JSON 会固定保存所绑定的计划编号、版本号、目标摘要、计划统计方法及样本量计算口径；不关联计划时原有分析与旧报告完全兼容。

## 接口

管理接口基址为 `/api/v1/projects/{id}/questionnaire`。使用 `GET` 读取状态，`PUT` 保存草稿。保存、发布和关闭操作以 `expectedRevision` 指定所读修订。`POST /publish` 发布，`POST /close` 关闭。`GET /responses.csv` 下载答卷，`POST /responses/material` 将当前答卷保存为项目资料。

填写链接使用 `/?questionnaire={publicId}`。公开接口 `GET /api/v1/questionnaires/{publicId}` 只返回标题、卷首语和已发布题目。向其子路径 `/responses` 提交答案获取回执。关闭或归档项目后，填写接口停止接收新答卷。首版沿用工作台的本机访问范围。

分析使用 `/api/v1/projects/{id}/surveys`。工作簿资料的 `GET /api/v1/projects/{id}/materials/{materialId}/survey-sheets` 返回数据工作表列表。创建分析时用 `options.sheet` 指定表名，可用 `options.planId` 关联同项目的分析计划版本（报告在 `report.planSource` 中保留不可变计划来源）。工作簿报告的 `rows[].sourceRow` 记录 Excel 行号，复核请求使用报告中的 `row` 序号。 [工作簿回归](<../internal/workbench/survey_workbook_test.go>)

样本量与分析计划使用 `/api/v1/projects/{id}/survey-plans`。`GET` 按版本号倒序返回项目全部计划版本及 `latestVersion`；`POST` 接受 `requestId`、`expectedVersion`（首次为 `0`，版本过期返回 409）、计划字段和 `sampleSizeInput`，保存后返回 `201`（同请求同内容幂等重放返回 `200`，同请求变更内容返回 `409`）。 [计划回归](<../internal/workbench/survey_plan_test.go>)
