# 互动问卷

从「互动问卷」模板建项，编辑问卷标题、卷首语和题目。首版支持单选和文本题，可逐题设为必答。草稿可反复保存。点击「发布问卷」后，当前修订成为填写页内容。复制链接即可在能访问同一工作台的浏览器打开填写页。点击「关闭回收」后停止接收新答卷，可继续下载已有数据。

## 数据与回收

- 问卷包含 1 至 20 道题。题目的编号与顺序决定导出列。每道单选题支持 2 至 12 个选项。
- 一次填写产生一条答卷回执。同一提交编号重试且内容一致时复用回执。每份问卷最多收集 1000 份答卷。文本题单项回答最多 320 个 UTF-8 字节，单份答卷的编码数据最多 7 KiB，以便回收数据能直接选入问卷分析。
- 管理页显示回收数量。答卷可下载为 CSV，也可保存至项目资料。打开「问卷分析」并刷新文件列表，选择导出的资料版本即可清洗和统计。
- CSV 包含答卷编号、提交时间、回收来源和各题的答案。项目资料按 CSV 摘要保存不可变版本。导出时会处理电子表格可能识别为公式的单元格。

## 交叉统计

在「问卷分析」开始分析所选 CSV，按需应用清洗规则和复核答卷。打开报告后，用「行分类」和「列分类」选择两个不同字段，点击「计算交叉统计」。表格仅计入两列均有回答的有效答卷，并显示缺失份数、各格次数及行列合计。每个字段最多 20 类，每个类别名最多 128 个 UTF-8 字节；适合单选或分组字段。

再次复核会按相同字段重算，生成独立报告。报告与 JSON 下载均保留原资料版本及 SHA-256。刷新文件列表发现同名新版时，旧报告仍可查看和下载；选择新版开始分析才会切换数据来源。

## 量表信度

在分析报告的「量表信度」中选取同一量表的 2 至 20 个数值题项，再点击「计算量表信度」。请先统一计分方向，例如在上传前完成反向题的反向计分。

Cronbach α 使用清洗和复核后有效且所选题项均为数值的答卷。报告分别列出纳入、缺失和非数值的份数。少于两份完整答卷或总分没有变异时，报告只显示样本计数。再次复核会重算并保存新报告，历次结果均可按原资料版本查看和下载。

## 接口

管理接口基址为 `/api/v1/projects/{id}/questionnaire`。使用 `GET` 读取状态，`PUT` 保存草稿。保存、发布和关闭操作以 `expectedRevision` 指定所读修订。`POST /publish` 发布，`POST /close` 关闭。`GET /responses.csv` 下载答卷，`POST /responses/material` 将当前答卷保存为项目资料。

填写链接使用 `/?questionnaire={publicId}`。公开接口 `GET /api/v1/questionnaires/{publicId}` 只返回标题、卷首语和已发布题目。向其子路径 `/responses` 提交答案获取回执。关闭或归档项目后，填写接口停止接收新答卷。首版沿用工作台的本机访问范围。

通过一次 Go HTTP 回归与一次 Chrome 联测核对保存、发布、重试、关闭和回收数据进入分析。
