# 专利技术交底工作流

创建「专利技术交底」项目时填写技术方案名称。启动 `patent-disclosure-v1` 时可填最多 4 KiB 的技术说明，并选择最多四份项目内的 UTF-8 文本或 Word 版本。材料编号与 SHA-256 随运行保存。写作使用说明和所选材料节选，也可从一段说明开始。

| 步骤 | 交付成果 |
| --- | --- |
| 固定技术材料 | 登记材料版本及内容摘要，列出需要补充的证据。 |
| 梳理技术方案草案 | 分列问题、组成、操作流程、实施依据和待核实项，默认等待确认。 |
| 编写技术交底稿 | 按确认的草案和原材料编写八节 Markdown 正文。 |
| 核对交底成果 | 核对规定章节，登记成稿、草案和固定材料的 SHA-256，并列出提交前需要人工复核的内容。 |

八节正文依次为「技术领域」「现有技术与问题」「技术方案」「实施方式」「附图说明」「建议保护点」「可选实施方案」「技术效果与待核实项」。术语和效果以材料可支持的范围为准。无法核实的技术效果、检索结论、专利号和未提供的实施细节均列入待核实项。首版交付附图说明，系统框图和流程图分一步接入。

可将成稿保存到工作区，配置 Word 组件后从固定版本导出可编辑 Word。运行沿用工作流的历史下载、暂停、继续和重跑，重跑上游会标记受影响的下游成果。

回归检查固定材料、默认检查点、同名换版、交底稿结构和 Word 保存入口。使用 `go test ./internal/workbench -run 'TestPatent|TestProjectTemplateCatalog' -count=1` 核对后端，使用 `pnpm --dir web run typecheck` 和浏览器核对建项与交付。
